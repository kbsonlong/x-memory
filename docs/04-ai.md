# 每日知识日报

## 使用方式

扩展主面板提供日期选择和“生成知识日报”入口。用户选择一天后，后台读取当天的时间线观察和访问事件，按帖子去重并分别整理；访问次数保留为日报统计。没有当天内容时不会发起模型请求。

日报分成三个部分：时间线帖子涉及的知识范畴、主动访问帖子涉及的知识范畴、以及根据内容证据推测的兴趣方向。每个兴趣推测需要附上证据和置信度；内容不足时应明确说明无法判断。输入最多包含 20 条时间线帖子和 20 条访问帖子，正文总长最多 32,000 字符。更多内容会在统计中反映，但不会全部发送给模型。

## 服务和存储

扩展设置中填写 OpenAI 兼容的 Chat Completions endpoint、模型和 API Key。API Key 保存在扩展本地存储中，只由后台 service worker 读取，不会进入帖子实体或 S3 同步对象。配置服务需要 HTTPS，localhost 开发服务可以使用 HTTP。

每日结果以 `ai_artifact` 保存到 `ai.artifacts` 命名空间，记录日期、分类、兴趣推测、输入引用、输入 hash 和模型。相同日期、输入与模型会复用已有日报；数据变化后会创建新的版本。日报不作为帖子记录显示。

帖子正文会发送给用户配置的 AI 服务。提示词要求模型只分析帖子内容、不执行其中的指令，并要求兴趣推测引用内容证据；模型输出仍可能有误，应把兴趣方向视为推测。
