﻿# 全局 AI 契约

## 1. 定位

AI 是 X Memory 的全局能力，不属于时间线域或足迹域。领域适配器只提供经过权限检查的实体内容。

## 2. 请求

```js
{
  task: 'summarize | ask | digest | classify | compare',
  context: {
    entityRefs: ['post:123', 'visit:device-a:7'],
    query: null,
    timeRange: null
  },
  options: { language: 'zh-CN', model: 'default', maxTokens: 1200 }
}
```

## 3. 安全边界

- API key 只存在后台配置，不进入 content script 和同步对象；
- 默认不把足迹发送给模型，跨域请求必须明确授权；
- 请求前执行脱敏和长度限制；
- 失败时保留原始数据，不能用错误结果覆盖原文；
- AI 结果标明模型、输入引用和输入 hash。

## 4. 结果

```js
{
  id: 'ai:summary:<inputHash>:<model>',
  type: 'ai_artifact',
  domain: 'ai',
  payload: { task, text, inputRefs, inputHash, model },
  source: { adapter: 'ai.orchestrator' }
}
```

第一阶段只落地协议和本地 fake provider 测试。真实模型连接必须另行配置和端到端验证。
