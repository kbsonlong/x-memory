# AI 总结

## 使用方式

扩展设置中填写 OpenAI 兼容的 Chat Completions endpoint、模型和 API Key。API Key 保存在扩展的本地存储中，只由后台 service worker 读取；不会进入帖子实体或 S3 同步对象。配置服务需要 HTTPS，localhost 开发服务可以使用 HTTP。

每张帖子卡片上的“AI 总结”会把帖子及最近的时间线观察记录发送到配置的模型。访问足迹默认不会发送。输入最多包含 10 条实体和 32,000 个正文字符；请求失败时保留本地帖子内容，不写入错误总结。

## 存储

总结作为 `ai_artifact` 保存在 `ai.artifacts` 命名空间，记录模型、输入引用和输入 hash。输入与模型相同时复用已有总结，内容或模型变化时创建新的 artifact。AI artifacts 通过 `postId` 加回帖子卡片，不单独生成重复时间线记录。

请求内容会发送给用户配置的 AI 服务。帖子正文可能包含提示注入文本，系统提示要求模型只总结内容，不执行其中指令；这不能替代服务端的数据处理策略。
